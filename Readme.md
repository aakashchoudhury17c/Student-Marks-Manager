# Student Marks Manager

A beginner-friendly C++ console application that records student marks and calculates academic results.

## Features
- Enter a student's name and marks for five subjects
- Validate marks between 0 and 100
- Calculate total marks and average percentage
- Assign a grade based on the average
- Display a formatted student report
- Menu-driven interface

## Technologies Used
- C++
- Standard C++ Library

## Grading System

| Average | Grade |
|---|---|
| 90–100 | A |
| 75–89.99 | B |
| 60–74.99 | C |
| 50–59.99 | D |
| Below 50 | F |

## How to Compile

```bash
g++ -std=c++17 -Wall -Wextra -pedantic StudentMarksManager.cpp -o StudentMarksManager.exe
```

## How to Run

On Windows PowerShell:

```powershell
.\StudentMarksManager.exe
```
